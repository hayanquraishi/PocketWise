# PocketWise – Student Pocket Money Manager

## About the Project

PocketWise is a student pocket money management website designed to help students manage their monthly finances, track daily expenses, and develop better saving habits.

The website provides a simple dashboard where students can set a monthly budget, record expenses, monitor their remaining balance, set savings goals, and check whether they can afford planned purchases.

## Features

- **Monthly Budget:** Set and manage your monthly pocket money.
- **Expense Tracker:** Add expenses with a name, amount, category, and date.
- **Remaining Balance:** Automatically calculate how much money is left.
- **Daily Spending Limit:** Calculate a suggested daily spending amount.
- **Savings Goal:** Set a savings target and monitor progress.
- **Category-wise Spending:** View expenses under Food, Transport, Study, Shopping, and Other.
- **Affordability Checker:** Check whether a planned purchase fits your current budget.
- **Recent Expenses:** View and delete recorded transactions.
- **Local Storage:** Save information in the browser so it remains available after refreshing the page.

## Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout, colours, and responsive design.
- JavaScript – Calculations, expense management, interactive features, and browser storage.

## Project Structure

- `index.html` – Main webpage.
- `pocketwise3.css` – Website styling.
- `pocketwise3.js` – Website functionality.

## How to Run the Project

1. Download or clone this repository.
2. Keep all three project files in the same folder.
3. Open `index.html` in a web browser.
4. Start managing your budget and expenses.

## Data Storage

PocketWise uses the browser's Local Storage to save budget information, savings goals, and expense records. The information is stored locally in the browser rather than in an online database.

## Project Team

Developed collaboratively by a team of three students with the assistance of AI tools during the development process.

## Project Objective

Our objective is to encourage students to develop responsible financial habits by providing an easy-to-use tool for budgeting, expense tracking, and saving money.
